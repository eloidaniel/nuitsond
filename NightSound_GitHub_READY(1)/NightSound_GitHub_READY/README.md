# Night Sound

Projet Android prêt pour GitHub Actions.

Le microphone est surveillé et un fichier WAV est créé uniquement lorsqu'un bruit dépasse le seuil choisi. Environ 5 secondes de pré-enregistrement sont conservées et l'enregistrement se termine après environ 3 secondes de silence.

## Compilation
1. Importer tout le contenu de ce dossier dans un dépôt GitHub.
2. Ouvrir Actions.
3. Cliquer sur Build Night Sound APK.
4. Cliquer sur Run workflow.
5. Attendre la coche verte.
6. Ouvrir l'exécution puis télécharger l'artefact NightSound-APK.
7. Décompresser l'artefact et installer app-debug.apk.
